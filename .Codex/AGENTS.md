## Project Overview

- Purpose: VoiceMode is a Python MCP server that adds voice interaction capabilities to AI assistants with local and cloud STT/TTS support.
- Tech stack: Python 3.10+, `uv`, FastMCP, pytest, MkDocs.
- Key files: `voice_mode/` for package code, `tests/` for automated tests, `README.md` for usage, `CLAUDE.md` for repo guidance, `pyproject.toml` for packaging and tool config.
- Conventions: Prefer `uv`/`make` workflows, keep changes scoped, and validate with the repo’s documented test commands.
